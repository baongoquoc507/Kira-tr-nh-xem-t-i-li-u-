# File cài đặt APK - Trình xem tài liệu Kira (Kira Document Viewer)

File APK đã được build hoàn chỉnh sẵn sàng để cài đặt trực tiếp lên thiết bị Android:

- **Tên tệp**: `KiraDocumentViewer.apk`
- **Đường dẫn**: `/release/KiraDocumentViewer.apk`
- **Phiên bản**: 1.0 (Build Debug signed)
- **Hệ điều hành yêu cầu**: Android 7.0 (API 24) trở lên

### Hướng dẫn cài đặt trên điện thoại Android:
1. Tải tệp `KiraDocumentViewer.apk` về điện thoại.
2. Mở tệp APK từ trình quản lý tệp (File Manager / Downloads).
3. Nếu thiết bị hiện thông báo "Cho phép cài đặt từ nguồn không xác định", chọn **Cho phép / Cho phép từ nguồn này**.
4. Chọn **Cài đặt (Install)** và hoàn tất.
